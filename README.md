# Full Stack Project

## Project Structure

- `backend/` - Node.js + Express API server
- `frontend/` - Next.js App Router + TypeScript client

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` in each project and configure as needed.
